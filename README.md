# LastTill

LastTill is a personal money-planning web app built to help everyday people — including students, employees, and entrepreneurs — avoid the stress of running out of money before their next payday. Instead of treating budgeting as a once-off exercise, LastTill works around real financial cycles. It divides spending into calendar-month categories, tracks a salary-to-salary (or income-to-income) cash-flow cycle, and continuously calculates how much money is safely available to spend each day until the next payout.

Beyond day-to-day budgeting, LastTill helps users manage their long-term financial wellbeing. Users can set and track savings goals for things they are working toward, while also maintaining a separate emergency fund reserved for genuine emergencies, such as medical expenses or urgent transportation. Keeping the emergency fund separate from ordinary spending money helps users avoid accidentally using it for everyday expenses.

A standout feature of LastTill is **TillCheck**, which allows users to check whether a purchase is affordable before spending money. TillCheck shows how the proposed purchase would affect the user's remaining budget and safe daily spending amount. This turns budgeting from a reactive, after-the-fact activity into a proactive decision-making tool. If a user overspends in a particular category, LastTill also notifies them that they have exceeded their budget.

Technically, LastTill is a multi-page frontend built using JavaScript and plain CSS, with Supabase providing authentication and database storage through PostgreSQL. The application is designed to be lightweight, fast, and affordable to host, while supporting secure, per-user data through Supabase Row Level Security (RLS).
